# Contributing to In-Place Animation Tool

Thank you for your interest in contributing to **In-Place Animation Tool**!

## How to Contribute

1. **Report Bugs:** Open an issue describing your Blender version, rig type (e.g., Metarig, Mixamo, Rigify), and what happened. If possible, attach a blend file or screenshot.
2. **Feature Requests:** Share ideas on game engine workflows, animation blending, or UI improvements.
3. **Pull Requests:**
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/awesome-feature`).
   - Commit your changes with clear messages.
   - Push to your branch and open a Pull Request.

## Code Guidelines
- Keep code compatible with Blender 3.0+ through Blender 4.5+.
- Maintain mathematical precision in 3D world coordinate space to prevent floor clipping/drift.
- Respect PEP 8 conventions where practical for Blender scripts.
